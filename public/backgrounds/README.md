# Background do jogo

Coloque a arte principal do cenário neste diretório com o nome:

```text
game-board.png
```

Dimensão da arte atual:

```text
941 x 1672 PNG
```

O app posiciona o grid jogável por cima do tabuleiro usando CSS. Se a arte mudar muito a posição do tabuleiro, ajuste as variáveis em `src/styles.css` dentro de `.gameStage`.
